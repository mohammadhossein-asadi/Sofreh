# 🍲 Sofreh (سفره)

**برنامه‌ریزی هفته‌ای غذا در چند دقیقه — برنامه‌ریزی غذای فارسی، با یا بدون هوش مصنوعی.**

Sofreh (سفره) اپلیکیشن وب برنامه‌ریزی غذای هفتگی است. چند سوال پاسخ دهید — چند نفر، ترجیحات رژیم، بودجه، منطقه — و یک برنامه‌ی کامل ۷ روزه با صبحانه، ناهار و شام برای هر روز، به‌همراه لیست خرید خودکار می‌سازد. با یک کلید API، یک LLM برنامه را حول ترجیح‌های شما می‌نویسد؛ بدون آن، یک تولیدکننده‌ی دمو درونی از مخزن دست‌پicked دست‌پیوند دسته‌بندی‌شده پر می‌کند، بنابراین اپلیکیشن کاملاً آفلاین کاربرد دارد.

رابط کاربری به زبان فارسی با پشتیبانی کامل RTL است.

![نمای برنامه هفتگی](./public/screenshot.png)

## ✨ ویژگی‌ها

- **سازنده‌ی برنامه‌ریزی ۴ مرحله‌ای** — خانوار و رژیم → بودجه → منطقه و سبک → برنامه، با مقادیر پیش‌فرض معقولی در هر مرحله
- **برنامه‌های هوشمند یا دمو** — تعویض بین حالت هوشمند (تولیدشده با LLM) و حالت دمو؛ اگر هیچ ارائه‌دهنده‌ای پیکربندی نشده یا درخواست شکست بخورد، اپلیکیشن به‌صورت نامرئی به تولیدکننده‌ی دمو سر می‌زند تا همیشه برنامه‌ای در دسترس باشد
- **ویراستار تعاملی برنامه** — هر وعده را با دستور پخت متفاوت تعویض کنید، یادداشتی برای هر روز اضافه کنید، سپس برنامه‌ای را ذخیره کنید
- **لیست خرید** — تجمیع‌شده از برنامه ذخیره‌شده با کادرهایOrt بررسی، خودکار بخش‌بندی‌شده به‌همراه هر روز
- **کتابخانه‌ی دستور پخت** — ۶۸ دستور پخت دمو (۱۰ دسته‌بندی کلاسیک، ۲۰ فصلی) با فیلترهای دسته‌بندی و جستجو
- **آگاه به منطقه** — یک شهر و سبک منطقه‌ای انتخاب کنید (تهران، اصفهان، شیراز، تبریز، کرمان، مشهد، احواز) تا فرهنگ غذایی شکل بگیرد
- **کاملاً کلاینت-دائمی** — برنامه‌ها و تنظیمات در `localStorage` ذخیره می‌شوند؛ بدون حساب، بدون دیتابیس سمت سرور
- **تنظیمات** — شهر، سبک منطقه‌ای، واحد پول، علاوه بر وارد/صادر کردن داده و بازگشت به پیش‌فرض
- **واکنش‌گرا و در دسترس‌ساز** — لایه‌بندی RTL، نشانه‌گذاری معنایی، حرکت نرم

هیچ دیتابیس و هیچ وضعیت سمت سرور وجود ندارد — همه چیز در مرورگر شما زندگی می‌کند.

## 🚀 شروع سریع

```bash
# ۱. کلون

# ۲. نصب
npm install

# ۳. (اختیاری) یک ارائه‌دهنده هوش مصنوعی پیکربندی کنید
cp .env.example .env.local
# .env.local را ویرایش کنید و حداقل یک کلید تنظیم کنید — میرافقت «ارائه‌دهندگان هوش مصنوعی» در زیر

# ۴. اجرا
npm run dev
```

در آدرس [http://localhost:3000](http://localhost:3000) باز می‌شود.

بدون کلید، اپلیکیشن در **حالت دمو** اجرا می‌شود: تولیدکننده‌ی برنامه از مخزن دستور پخت درونی‌اش استفاده می‌کند. برای امتحان برنامه‌های هوشمند، یک کلید اضافه کنید و حالت را در سازنده به «هوشمند» تغییر دهید.

### اسکریپت‌ها

| دستور               | کاری که انجام می‌دهد                        |
| --------------------- | ------------------------------------- |
| `npm run dev`         | سرور توسعه در :3000                   |
| `npm run build`       | بیلد نسخه‌ی تولید                      |
| `npm run start`       | ارائه نسخه‌ی تولید            |
| `npm run lint` / `npm run typecheck` | `tsc --noEmit` تایپ‌چک |
| `npm test`            | Vitest (یک‌باره، از طریق Vite)         |

نیاز به Node.js 18+ دارد.

## 🤖 ارائه‌دهندگان هوش مصنوعی

برنامه‌های هوشمند توسط یک مسیر `POST /api/plan` تک‌گانه تولید می‌شوند. سرور ارائه‌دهندگان را **به این ترتیب** امتحان می‌کند و اولین کسی را استفاده می‌کند که کلید었다는 پیکربندی شده:

| #  | ارائه‌دهنده   | متغیر محیط            | یادداشت                                              |
| -- | ---------- | ------------------ | -------------------------------------------------- |
| ۱  | Groq       | `GROQ_API_KEY`     | پیشنهادی — سریع و دارای سطح رایگان مهمان‌نواز    |
| ۲  | OpenRouter | `OPENROUTER_API_KEY` | یک کلید برای ۴۰۰+ مدل                     |
| ۳  | Mistral    | `MISTRAL_API_KEY`  |                                                    |
| ۴  | DeepSeek   | `DEEPSEEK_API_KEY` |                                                    |
| ۵  | GLM        | `GLM_API_KEY`      | Zhipu BigModel                                     |
| ۶  | OpenAI     | `OPENAI_API_KEY`   | GPT-4o-mini                                        |
| ۷  | Gemini     | `GEMINI_API_KEY`   | Gemini 2.0 Flash                                   |

نکات کلیدی:

- **فقط یک کلید نیاز دارید.** آن را در `.env.local` تنظیم کنید (ر.ک. `.env.example`) و سرور توسعه را مجددا راه‌اندازی کنید.
- **بدون کلید = حالت دمو.** اگر هیچ چیزی پیکربندی نشده، مسیر API برنامه‌ای از تولیدکننده‌ی درونی برمی‌گرداند و رابط کاربری ن카슈‌های حالت دمو نشان می‌دهد.
- **پارس قاچ‌ناپذیر.** پاسخ باید با یک اسکیمای Zod صریح تطابق داشته باشد؛ هر شکست پارس به مخزن دمو سر می‌زند تا رابط کاربری هرگز داده‌ی شکسته‌ی دریافت نکند.
- **بدون استریم، بدون AI SDK.** مسیر از `fetch` ساده به انتهای `chat/completions` ارائه‌دهنده با حالت JSON استفاده می‌کند — کوچک و عمداً بدون وابستگی.
- پیش‌دعوت و خروجی به زبان فارسی هستند (روزها، خوراک‌ها، مواد اولیه با مقدار و قیمت، کل هزینه به ازای هر روز).
